## project title
Temperature converter Machine

A simple and interactive menu-drive Python program to convert temperature between Celsius and fahrenheit

## Overview
The temperature converter Machine is a lightweight python script desgined to perfrom temperature unit conversions based on user choice.Its provides an intuitive terminal menu for quick and accurate conversions 
## Features
** Celsisus to Fahrenheit conversion

**Fahrenheit to Celsisus conversion

** Interactive Menu system:loop based menu that runs continuously until you choose to exit or provide invalid input

**Simple function:Uses modular python functions for clean conversion calculations
